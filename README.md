# ফলবৃত্ত (Folbritto) — ফলের নির্ভরযোগ্য বাংলা ডিজিটাল তথ্যভান্ডার

> **“ফল চিনুন, জেনে খান।”**

**ফলবৃত্ত** হলো বাংলাদেশে প্রাপ্ত স্থানীয়ভাবে উৎপাদিত, আমদানিকৃত এবং ঐতিহ্যবাহী কম পরিচিত ফলসমূহের একটি পূর্ণাঙ্গ, নির্ভরযোগ্য ও মার্জিত বাংলা ডিজিটাল জ্ঞানকোষ। 

এখানে প্রতিটি ফলের সঠিক বোটানিক্যাল পরিচয়, আন্তর্জাতিকভাবে স্বীকৃত পুষ্টিপরিসংখ্যান, পাকার প্রকৃত মৌসুম, খাওয়া ও সংরক্ষণের স্বাস্থ্যসম্মত নিয়মাবলী এবং চিকিৎসাগত সতর্কতা এক জায়গায় সুন্দর ও সুলভ বাংলায় উপস্থাপন করা হয়েছে।

## 🌟 মূল বৈশিষ্ট্যসমূহ

1. **৫০টি ফলের সম্পূর্ণ ক্যাটালগ**: জাতীয় ও স্থানীয়ভাবে সুপরিচিত ফল থেকে শুরু করে বিলুপ্তপ্রায় দেশি ফল এবং জনপ্রিয় আমদানিকৃত ফল।
2. **একক পৃষ্ঠার ডিরেক্টরি**: কোনো পেজিনেশন ছাড়াই ৫০টি ফলের কার্ড ব্রাউজ করার সুবিধা, যেখানে রয়েছে লেজি ইমেজ লোডিং।
3. **লাইভ বাংলা ও ইংরেজি অনুসন্ধান**: বাংলা নাম, ইংরেজি নাম এবং স্থানীয় প্রচলিত নাম বা উপনাম (যেমন: বরই/কুল, আনার/বেদানা/ডালিম) দিয়ে দ্রুত খোঁজার সুবিধা।
4. **বহুমাত্রিক ফিল্টারিং**:
   - **মৌসুম ফিল্টার**: সব, গ্রীষ্ম, বর্ষা, শরৎ, হেমন্ত, শীত, বসন্ত, সারা বছর।
   - **প্রাপ্যতা ফিল্টার**: সব, বাংলাদেশে উৎপাদিত, আমদানিকৃত, সীমিত প্রাপ্যতা।
   - **সাজানোর সুবিধা**: বাংলা নাম (অ-হ) অথবা ইংরেজি নাম (A-Z) অনুযায়ী অ্যালফাবেটিকাল সর্টিং।
   - ব্রাউজারের হিস্ট্রি ও URL কুয়েরি প্যারামিটার সাপোর্ট (`?q=...&season=...`)।
5. **নিবেদিত প্রি-রেন্ডার স্ট্যাটিক পেজ**: প্রতিটি ফলের জন্য বিস্তারিত `/fruits/[slug]/` রুট, যেখানে রয়েছে:
   - বোটানিক্যাল পরিচয় ও বৈজ্ঞানিক নাম।
   - প্রতি ১০০ গ্রাম ভক্ষণযোগ্য অংশের ভিত্তিতে USDA ও FAO ভিত্তিক পুষ্টিমান তালিকা।
   - বিজ্ঞানসম্মত স্বাস্থ্য উপকারিতা (কোনো অতিপ্রাকৃতিক অবৈজ্ঞানিক দাবি ছাড়া)।
   - খাওয়ার সঠিক সময়, নিয়ম ও প্রচলিত ভ্রান্ত ধারণা খণ্ডন।
   - গুরুত্বপূর্ণ মেডিকেল সতর্কতা (যেমন: কিডনি রোগীদের জন্য কামরাঙার নিষেধাজ্ঞা, সাইট্রাস ও ওষুধের ইন্টার‍্যাকশন, গর্ভাবস্থায় কাঁচা পেঁপে পরিহার)।
   - প্রতিটি ফলের জন্য ৩–৫টি প্রাসঙ্গিক প্রশ্নোত্তর (FAQs)।
   - সক্রিয় ও ক্লিকযোগ্য প্রাতিষ্ঠানিক তথ্যসূত্র।
   - একই মৌসুম ও গোত্রের ৪টি সংশ্লিষ্ট ফলের সংযোগ।
6. **১:১ স্কয়ার ইমেজ রেশিও**: মোবাইল থেকে ডেস্কটপ পর্যন্ত প্রতিটি ব্রেকপয়েন্টে ফলের ফটোগ্রাফ নিখুঁত ১:১ স্কয়ার রেশিও ও ক্রাফটেড ক্রিম ব্যাকগ্রাউন্ডে প্রদর্শিত।
7. **অ্যাক্সেসিবিলিটি ও রেসপনসিভনেস**: কীবোর্ড নেভিগেশন, স্ক্রিন রিডার ফ্রেন্ডলি ল্যান্ডমার্কস, ৪৪ পিক্সেল স্পর্শ নিশানা এবং গাঢ় বৈপরীত্যের বাংলা টাইপোগ্রাফি (Noto Sans Bengali / Hind Siliguri)।

## 🚀 লোকাল সেটআপ ও রান করার নিয়ম

### ১. ডিপেন্ডেন্সি ইনস্টল
```bash
npm install
```

### ২. ডেভেলপমেন্ট সার্ভার চালু
```bash
npm run dev
```
ব্রাউজারে চালু করুন: `http://localhost:4321/folbritto/`

### ৩. প্রোডাকশন স্ট্যাটিক বিল্ড
```bash
npm run build
```
এটি `dist/` ফোল্ডারে সম্পূর্ণ ৫০টি ফলের রুটসহ মোট ৫৫টি স্ট্যাটিক পেজ তৈরি করবে।

### ৪. লোকাল প্রিভিউ
```bash
npm run preview
```

## 📝 নতুন ফল যুক্ত বা কন্টেন্ট সম্পাদনা

সকল ফলের তথ্য `src/data/fruits.ts` ফাইলে সুবিন্যস্ত রয়েছে। একটি নতুন ফল যুক্ত করতে বা তথ্য হালনাগাদ করতে:
1. `src/data/fruits.ts` ফাইলটি খুলুন।
2. নির্ধারিত ইন্টারফেস অনুযায়ী নতুন অবজেক্টটি যুক্ত বা সম্পাদনা করুন:
   - `slug`: ছোট হাতের হাইফেনযুক্ত অনন্য নাম।
   - `nameBn`: প্রমিত বাংলা নাম।
   - `scientificName`: সঠিক ল্যাটিন বৈজ্ঞানিক নাম।
   - `nutrition`: প্রতি ১০০ গ্রাম ভক্ষণযোগ্য অংশের পুষ্টিমান ও সুনির্দিষ্ট সোর্স।
   - `cautions`: প্রয়োজনীয় মেডিকেল সতর্কতা।
3. নতুন ছবি যোগ করতে `public/images/fruits/{slug}.webp` পাথে ১:১ অনুপাতের ছবি রাখুন এবং `hasCustomPhoto: true` ফ্ল্যাগ দিন।
